# The site

Arguments: `$ARGUMENTS`. Target defaults to `dev` if it's running, otherwise `prod`. Read
`.claude/skills/SERVICES.md` first.

| Target | Base URL |
|---|---|
| dev | `http://localhost:4321` |
| preview | `http://localhost:8787` (seed its R2 first, or photo pages answer 500; see SERVICES.md) |
| prod | `https://diego-narvaez-photography.org` |

If a local target isn't running, say so and offer `/service-start`. Everything here is read-only.

## Operations

| Ask | How |
|---|---|
| A page | `curl -s -o <scratchpad>/page.html -w '%{http_code} %{content_type} %{time_total}s\n' <base><path>`, then look at its `<title>`, `lang`, canonical and anything the user asked about. Spanish pages are under `/es/`. |
| Which build is it | The footer label (SERVICES.md). Dev reads it once, when the server starts, so after new commits it shows an old label until `/service-restart dev`. |
| Headers | `curl -sI <base><path>`. Production must send HSTS, CSP, `X-Frame-Options: DENY`, `X-Content-Type-Options`, Referrer-Policy and Permissions-Policy (`public/_headers`). In dev, only the pages rendered on request (home, galleries, Admin) get them, from `src/middleware.ts`; static pages like `/about/` don't. Dev's CSP also allows `http://localhost:*` and `http://127.0.0.1:*` in `connect-src` and `img-src`, on purpose (SERVICES.md, "The Admin page against the local API"); everything else must match `_headers`. Preview and prod send `_headers` as it is, on every page. |
| Photo list | `curl -s <base>/api/photos.json`, summarized with node, not dumped. Each entry is `{category, id, data}`, and the fields are under `data` (`title`, `featured`, `heroBackground`, `order`, `takenAt`…). Count per category, `data.featured` and `data.heroBackground`. A 500 means the manifest in R2 is missing or unreadable. |
| Sitemap | Preview and prod only: it's generated by the build, so dev answers 404. `<base>/sitemap-index.xml` → its `sitemap-0.xml`; count the URLs per language. |
| 404s | `curl -s -o /dev/null -w '%{http_code}' <base>/no-such-page/` and `/es/no-such-page/` must be 404. On preview and prod each gets its language's page (`lang="en"`/`"es"`). Dev answers a plain-text "Not found", which is expected. |
| Location default | Dev only: `<base>/?geo=MX` simulates Cloudflare's country (README, "Location-based default language"). |
| Smoke check | `npm run smoke -- <base>` (add `--wait` right after a deploy). It checks every sitemap page, both contact forms and their keys, every R2 photo URL, the 404s, robots.txt and the headers. Failures on prod get filed per `.claude/skills/REPORTING.md`. |
| Speed and scores | /test-lighthouse. |

## Logs

| Target | How |
|---|---|
| dev | `npx astro dev logs` (`--follow` in the background for live) |
| preview | `tail -n 50 <scratchpad>/preview.log` (where /service-start wrote it) |
| prod | `npx wrangler tail photography-site --format pretty`, with `run_in_background`, filtered with `--status error` or `--search <text>` when looking for something. Stop it when done (it streams until killed); it shows live requests only, not history. |

## Report

What was asked, answered directly: status codes, the label, counts, the headers that are missing or wrong, smoke
results. Quote only the relevant lines of HTML or logs.
